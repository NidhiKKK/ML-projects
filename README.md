Human activity recognition involves data collected using the accelerometer sensor of smartphones while performing the activities such as jogging, sitting, standing, walking, walking downstairs, and walking upstairs. With the help of an embedded accelerometer, linear acceleration is assembled across the entire 3 axes at a sustained sampling rate of 20Hz.The previously
mentioned activities are marked with specific labels. Further, the process of feature extraction was implemented by extracting time-domain features using the overlapping windowing technique. Afterward, machine learning classifiers are then
used to analyze data. The effect of the machine learning model
is examined based on overall accuracy, recall, and precision
values.
